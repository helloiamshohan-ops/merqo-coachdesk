# MERQO CoachDesk — উন্নয়ন সংস্করণের ব্যবহার নির্দেশিকা

> এই নির্দেশিকা বর্তমান উন্নয়ন সংস্করণের কাজ বর্ণনা করে। এটি পূর্ণ বাণিজ্যিক পণ্যের ব্যবহার নির্দেশিকা নয়।

## শুরু করা

প্রয়োজন: Node.js 22 বা পরবর্তী সংস্করণ। প্রকল্পের মূল ফোল্ডারে চালান:

```bash
npm test
npm run check
npm run dev
```

তারপর ব্রাউজারে `http://localhost:4310` খুলুন। এই উন্নয়ন সংস্করণের স্থানীয় প্রবেশ:

- ব্যবহারকারীর নাম: `admin`
- পাসওয়ার্ড: `local-development-only`

বাস্তব গ্রাহক স্থাপনার জন্য এই পাসওয়ার্ড ব্যবহার করবেন না।

## ড্যাশবোর্ড

ড্যাশবোর্ডে সক্রিয় শিক্ষার্থী, কোর্স, ব্যাচ, বকেয়া, আজকের সংগ্রহ এবং কার্যক্রমের সংখ্যা সার্ভার থেকে আসে। কোনো কৃত্রিম সংখ্যা দেখানো হয় না। ব্যবহারকারীর অনুমতি না থাকলে আর্থিক তথ্য গোপন থাকে।

## শিক্ষার্থী যোগ করা

১. বাম পাশের **শিক্ষার্থী** নির্বাচন করুন।
২. **নতুন শিক্ষার্থী** চাপুন।
৩. বাংলা নাম আবশ্যক; ইংরেজি নাম, ফোন, জন্মতারিখ ও ঠিকানা ঐচ্ছিক।
৪. **সংরক্ষণ করুন** চাপুন।

শিক্ষার্থী আইডি সার্ভার তৈরি করে। একই মাস্টার শিক্ষার্থীর ভবিষ্যৎ ভর্তি আলাদা রেকর্ড হবে; নাম পরিবর্তন করে পুরনো ভর্তি ইতিহাস মুছে ফেলা হয় না।

## আর্থিক API পরীক্ষার সংক্ষিপ্ত নিয়ম

বর্তমান UI-তে পূর্ণ অর্থ মডিউল নেই, কিন্তু সেবায় ফি আইটেম, আংশিক পেমেন্ট, এক পেমেন্টকে একাধিক ফি আইটেমে বরাদ্দ, বকেয়া এবং পুনরায় পাঠানো পেমেন্ট ঠেকানোর পরিচিতি আছে। এগুলো স্বয়ংক্রিয় পরীক্ষায় যাচাই করা হয়েছে।

## তথ্য নিরাপত্তা

উন্নয়ন ডেটা `COACHDESK_DATA_DIR`-এর অধীনে থাকে। সেটি গ্রাহক ডেটার ব্যাকআপ নয়। বর্তমান সংস্করণে ব্যাকআপ/পুনরুদ্ধার মডিউল নেই; বাণিজ্যিক স্থাপনার আগে এটি সম্পূর্ণ ও যাচাই করা আবশ্যক।

## সীমাবদ্ধতা

পূর্ণ উপস্থিতি, পরীক্ষা, ফল, স্টাফ, রিপোর্ট, আমদানি/রপ্তানি, ব্যাকআপ, Windows ডেস্কটপ, PostgreSQL এবং লাইসেন্স পুনরুদ্ধার UI এখনো তৈরি/যাচাই হয়নি। বিস্তারিত `docs/PROJECT_STATUS.md`-তে আছে।
